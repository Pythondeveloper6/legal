Common questions

Where does Lectern store my courses? In whatever folder you choose as your workspace (Settings → General → Workspace folder, default ~/Data/Content/Courses-content). Every subfolder there containing Markdown files shows up as a course in the sidebar. Nothing is copied elsewhere — edit the files with any other editor and Lectern picks up the changes.

Which AI provider should I use? Settings → Provider lets you switch any time: - Claude (API) — needs an Anthropic API key from console.anthropic.com. Fastest to set up, includes web search and tool use. - Claude (Code CLI) — reuses your existing claude login, no API key needed, as long as the CLI is installed and on your PATH (or pointed at directly). - Ollama — fully local and free once you've pulled a model with ollama pull <model>. Nothing leaves your machine. Requires Ollama running at http://localhost:11434 (or a custom URL you set).

Use "Test connection" in Settings → Provider to confirm your setup before generating a course or asking a question.

Why did course generation or Ask-AI fail? Almost always a provider issue: a missing/invalid API key, the claude CLI not found at the expected path, or Ollama not running. Check Settings → Provider → Test connection first — the error message there is the same one the app hit.

What's a course profile, and can I write my own? A course profile (Settings → Main Prompt) is a Markdown style guide that tells Lectern how to structure a generated course — required sections, whether Mermaid diagrams or comparison tables are expected, file naming, and so on. Lectern ships with two: a numbered "deep dive" profile and an interview-style Q&A profile. Drop your own .md profile into the user profiles folder to define a custom structure, and pick it when creating a course.

What are Extra Prompts? Reusable snippets of instruction (Settings → Extra Prompts) that get appended to either course generation, Ask-AI answers, or both — without editing your base course profile. Handy for house rules like "always include a runnable code example" that apply across every course.

Can I search my notes? Yes — the Notes panel searches every saved answer across all courses (backed by SQLite full-text search), and you can filter by course or click through to the source file.

Does Lectern work offline? Browsing, editing, and previewing your courses always works offline — that's just local files. AI features need whichever backend you've chosen to be reachable: Ollama needs to be running locally, Claude (API) and Claude (Code CLI) need internet access.
