Lectern — Privacy Policy

Last updated: 12 July 2026

Lectern is a desktop app for building and studying Markdown courses. This policy explains, precisely, what happens to your data — including what leaves your device when you turn on an AI feature.

The short version

  • Lectern's developer collects nothing. There is no Lectern server, no account, no analytics, and no crash reporting anywhere in the app.
  • Your course files live as plain Markdown on your disk, in whatever folder you choose. Notes, extra prompts, and settings live in a local app-data folder.
  • AI features send data to whichever provider you pick, using your own credentials:
  • Ollama — 100% local. Nothing leaves your machine.
  • Claude (API) — the current lesson's text and your question are sent directly to Anthropic's API using the API key you provide.
  • Claude (Code CLI) — Lectern runs your locally-installed claude CLI as a subprocess and streams its output back; any network activity is the CLI's own, under your existing Claude Code login.
  • No advertising, no third-party trackers, no data resale — there's no mechanism in the app to do any of that.

How Lectern works

Your workspace folder. In Settings → General you point Lectern at a folder (default ~/Data/Content/Courses-content). Lectern reads that folder directly with Node's filesystem APIs to list courses and files, and writes .md files back when you save. This never touches the network.

Local app data. Lectern keeps a few things in its private app-data directory (~/Library/Application Support/Lectern on macOS), never transmitted anywhere: - settings.json — your workspace folder, active AI provider, theme, and other preferences (via electron-store). - secrets.json — your Anthropic API key, Ollama base URL, CLI path, and optional web-search keys (Tavily/Brave), stored with electron-store's built-in obfuscation. This is not strong encryption — it deters casual inspection of the file, not a determined attacker with access to your Mac. Keep your device secure the way you would for any locally-stored credential. - lectern.db — a local SQLite database holding your Notes (with full-text search), saved Extra Prompts, quiz state, and Pomodoro session history. All of it is written from data you already have (your course files, your questions, your answers) — nothing is fetched from or synced to a remote service.

AI providers, and what each one sees. Lectern supports three interchangeable backends, chosen in Settings → Provider: - Ollama — talks only to a local Ollama server (default http://localhost:11434). No internet connection is made. - Claude (API) — when you ask a question or generate a course, the relevant lesson content, your prompt, and (for generation) your course profile are sent to Anthropic's API over HTTPS, authenticated with the API key you entered. This is the same connection you'd get using the Anthropic SDK directly; Anthropic's own privacy policy governs that data once it leaves your device. - Claude (Code CLI) — Lectern spawns the claude binary already on your system (ClaudeCLIProvider) and streams its JSON output. Whatever that CLI sends is under your existing Claude Code account, outside Lectern's control or visibility.

Optional web search. If you add a Tavily or Brave Search API key in Settings, and the active provider doesn't already have built-in search, Lectern sends your search query to that provider's API. This is off unless you supply a key.

Course profiles and templates. The Markdown style guides that shape generated courses (resources/profiles/agents.md, interview.md, plus any you add) are read from local files — no network involved.

Your control

  • Switch providers, clear your API keys, or point Lectern at a different workspace folder at any time from Settings.
  • Delete a Note from the Notes panel, or delete a file directly from disk — Lectern has no separate copy of your course content beyond what you can see in your workspace folder.
  • Turn on "Sync notes to disk" in Settings → General to mirror your local notes database into a _notes/ folder inside each course, if you want them versioned alongside your Markdown in git.
  • Uninstalling Lectern and deleting its Application Support folder removes all local app data. Your course Markdown files are untouched, since they live in the workspace folder you chose.

Children

Lectern is a general-purpose study tool and collects no personal information from anyone, including children.
