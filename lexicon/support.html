Common questions

Where are my documents stored? Wherever you put them. Lexicon edits the markdown files in the workspace folder you open — nothing is copied off your Mac.

How do I open my course folder? Use File → Open Workspace… (⌘O) and pick the folder of markdown files.

Export to Word, EPUB, or PDF isn't working. Those formats use pandoc. Install it (for example brew install pandoc), then restart Lexicon. PDF export also needs a LaTeX engine such as xelatex. HTML export and static-site export work without pandoc.

What do the colored dots in the sidebar mean? They mirror git status for the file: orange = modified, green = staged, blue = untracked. Lexicon only reads git status; it never commits or pushes.

How do I reset the app? Open Settings → Privacy → Reset to clear recent workspaces and restore default preferences. Your markdown files are never touched.
