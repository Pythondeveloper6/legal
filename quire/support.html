FAQ

What file types does Quire open?

Quire is a read-only viewer for a broad range of document formats, including:

  • Word documents (.doc, .docx), OpenDocument Text (.odt), Rich Text (.rtf, .rtfd)
  • HTML and web archives
  • PDF
  • Plain text and Markdown
  • eBooks (EPUB, FictionBook)
  • CSV and other structured/tabular text
  • Source code, JSON, plist, log files, diffs, and subtitles
  • Archives (zip and similar) — browsed without fully extracting them
  • Images, audio, and video
  • Email (.eml)

If a file's type isn't one Quire specifically recognizes, it falls back to a plain-text or generic preview where possible.

Why is remote content blocked?

Some HTML documents and web archives link to images, fonts, or other resources hosted online. Loading them tells whoever hosts that content your IP address and that you opened the document. Quire blocks all such network requests by default so opening a document never quietly reaches out to the internet. You can allow it for a single document from a banner on that document's tab, or turn it on globally in Settings → Privacy.

Why does a file show as "missing" in the sidebar?

Quire doesn't keep a copy of files you open — it keeps a security-scoped bookmark, the sandboxed macOS mechanism for reopening a file you previously granted access to without asking again. If that file is moved, renamed, deleted, or its volume is unmounted, the bookmark can no longer resolve, and Quire shows it as "Missing" in the sidebar rather than silently dropping it. Locate the file again and reopen it to restore access — the old entry can then be removed.

Does Quire ever modify my files?

No. Quire is read-only. It never writes to, moves, renames, or deletes the documents you open. The only things Quire writes are its own local data — recents, folders, settings, and search cache — described in the Privacy Policy.

Where is my data stored?

Locally, under ~/Library/Application Support/com.mahmoudahmed.quire/ and macOS UserDefaults. See the Privacy Policy for details.
