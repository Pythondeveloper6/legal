Common questions

Why does TouchDeck need Accessibility permission? It uses Accessibility only to send keystrokes and shortcuts to the app you're using, and to read that app's menu shortcuts so it can offer them as buttons. It never records what you type. See the Privacy Policy for details.

The bar isn't sending keystrokes. Open System Settings → Privacy & Security → Accessibility and make sure TouchDeck is turned on. If it's already listed, toggle it off and on again, then relaunch.

Where is my configuration stored? In a JSON file in TouchDeck's Application Support folder on your Mac. Nothing is synced or sent anywhere.

How do I start over? Open Settings → About → "Reset to defaults."

How do I show or hide the bar? Use the focus hotkey (default ⌃⌥Space), or change the placement mode in Settings → General.
