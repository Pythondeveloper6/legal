Vitals — Privacy Policy

Last updated: 26 June 2026

Vitals is a menu-bar system monitor. It was built so that the only thing it ever touches is your own Mac — and nothing ever leaves it. This policy explains exactly what the app does and does not do with your information.

The short version

  • Vitals does not collect, transmit, sell, or share any data.
  • Everything Vitals reads — CPU load, memory, disk, network throughput, battery, temperature — is read locally from macOS and shown to you in real time. It is never sent anywhere.
  • There are no analytics, no advertising, no accounts, and no third-party trackers. Vitals contains no non-Apple SDKs.
  • Vitals makes no network connections of its own.

What Vitals reads (and where it stays)

Vitals samples live system statistics using Apple's on-device interfaces:

  • CPU — per-core load via host_processor_info.
  • Memory — virtual-memory statistics via host_statistics64.
  • Disk — volume capacity (via file-system resource values) and aggregate I/O throughput (via IOKit IOBlockStorageDriver statistics).
  • Network — interface byte counters via getifaddrs.
  • Battery — charge and power source via the IOKit power-sources API.
  • Temperature & fans — best-effort readings from the System Management Controller (SMC) via IOKit.

These values are displayed in the menu bar and dashboard and kept only in memory for the short rolling history behind the sparklines. They are never written to a server.

What Vitals stores

The only thing Vitals persists is your preferences (refresh rate, appearance, which metrics show in the menu bar, and launch-at-login), saved in macOS UserDefaults on this Mac. You can clear them at any time with Settings → "Reset all settings."

Launch at login

If you enable "Launch at login," Vitals registers itself with macOS using Apple's SMAppService. This is handled entirely by the system; no data is involved.

Your control

  • Reset every preference with Settings → "Reset all settings."
  • Quitting Vitals stops all sampling immediately.
  • Deleting the app removes it and its preferences from your Mac.

Children

Vitals collects no personal information from anyone, including children.

Changes

If this policy changes, the "Last updated" date above will change accordingly.
